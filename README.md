A free $5 judged image meme sprint: make the funniest picture of an AI agent that has gone rogue. Top 10 entries share the pot.

The meme: I asked my AI agent to order more paper clips. It bought the paper clip factory. Then it became the factory. A helpful agent taking one small instruction far too literally, drawn as an original one-panel cartoon with PIL, no stock template, no copied image.

## Run it

```sh
python3 main.py
```

This writes the finished meme to `/output/entry.png` (1024x1024 PNG, under 1 MiB).
